Ghost 共享自测页

开会前用这个页面看一眼：别人收到的共享画面里，你的半透明窗口是不是真的不见了。全程只在你的浏览器里运行，画面不会上传。

  1. 点下面的「打开测试窗口」，会弹出一个品红色的小窗口。
  2. 在菜单栏 👻 里打开「共享/录屏时隐藏」，再点一下品红窗口，按 ⌃⌥T 让它变成半透明。
  3. 回到这个页面，点「开始共享」，选「整个屏幕」。
  4. 看结果和下面的预览。预览就是对方看到的画面。
未开始

也可以不用测试窗口，直接把你要藏的窗口调成半透明，再看预览里有没有它。这个页面调用的是网页会议用的屏幕共享接口，结果和 Meet、Zoom 网页版、飞书网页版一致；桌面会议客户端请用它们自己的共享预览检查。建议用 Chrome 或 Edge。

Windows 版（Beta）要往目标程序里注入一个小 DLL 才能隐藏窗口。如果对浏览器弹出的测试窗口隐藏时报错，换一个普通窗口（比如记事本）调成半透明，再看预览里有没有它。
