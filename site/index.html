它能做什么

一个住在菜单栏里的 👻，不占 Dock，不改任何 App。

🪟

任意窗口半透明

鼠标停在窗口标题栏上，出现滑块，拖到想要的透明度。窗口照常能点、能打字。

🙈

共享时只有你看得见

打开「共享/录屏时隐藏」，被调透明的窗口不会出现在屏幕共享、录屏和截图里。适合讲稿、提词、私人消息。

🛡️

不用关 SIP

不注入、不破解系统，只需要「屏幕录制」权限。代码完全开源，全部在本机运行，不联网。

安装

大约 1 分钟。

  1. 点上面的「下载 macOS 版」，解压得到 Ghost.app，拖进「应用程序」文件夹。
  2. 双击打开。如果提示「无法验证开发者」：打开 系统设置 → 隐私与安全性，在页面底部点「仍要打开」。也可以在终端运行一次： 
    xattr -dr com.apple.quarantine /Applications/Ghost.app
  3. 首次打开会请求「屏幕录制」权限：在 系统设置 → 隐私与安全性 → 屏幕录制 里打开 Ghost，然后点菜单栏 👻 → 退出，再重新打开。
  4. 完成。菜单栏出现 👻 就可以用了。想开机自动启动：👻 → 登录时自动启动。

怎么用

三种方式，选顺手的。

🖱️

悬停标题栏

在任意窗口的标题栏停 0.3 秒，右上角出现滑块。拖到 100% 恢复原样。

⌨️

快捷键 ⌃⌥T

一键切换最前面那个窗口的透明状态，默认透明度可以在菜单里改。

👻

菜单栏

列出所有窗口和当前透明度，点一下切换；也能一键全部恢复、开关「共享/录屏时隐藏」。

「共享时隐藏」支持哪些软件

隐藏能不能生效，取决于共享/录屏软件是否遵守 macOS 的「不要截取此窗口」标记。正式使用前，建议先用会议软件的共享预览，或另一台设备入会看一眼。

软件结果
Chrome 的网页屏幕共享（网页会议用的就是它）✓ 已实测可隐藏
macOS 全屏截图（⇧⌘3）✓ 已实测可隐藏
Chrome / Edge 里的 Google Meet、Zoom / Teams / 飞书网页版会议，⇧⌘5 录屏、QuickTime、Cap同一套系统机制，预期可以，建议先自测
Zoom / Teams 桌面客户端、Safari未测试，请先自测
飞书 / Lark 桌面客户端的录屏和共享✗ 无法隐藏（它直接抓取屏幕原始画面）

建议：需要隐藏窗口的会议，用 Chrome 打开网页版并选择共享「整个屏幕」。

Windows 版 Beta

原生 Windows 移植版，交互和 macOS 版一致：悬停标题栏出滑块、Ctrl+Alt+T 一键切换、托盘 👻 管理所有窗口。目前是实验版——已通过 CI 编译，但还没在真机上逐项验证，请当早期测试版用。

🪟

直接改真窗口

用系统的分层窗口 API（WS_EX_LAYERED）让窗口半透明，不像 macOS 版那样靠截屏叠层，开销更小。

🙈

共享时隐藏

用 SetWindowDisplayAffinity 把窗口排除出截屏。该调用只作用于自己进程，所以 Ghost 会往目标进程注入一个用完即卸载的小 DLL。

⚠️

已知限制

注入对提权/受保护进程无效（除非以管理员运行），可能被杀毒拦截，不支持 32 位程序；飞书桌面端抓原始屏幕，隐藏不了。

  1. 点上面的「下载 Windows 版」，解压。Intel/AMD 电脑用 x64 文件夹，ARM 电脑用 arm64。
  2. 把 Ghost.exe 和 ghost_inject.dll 放在同一个文件夹——共享隐藏需要 DLL 在 exe 旁边。
  3. 运行 Ghost.exe。没有代码签名，SmartScreen 会提示「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。它住在托盘 👻，没有窗口。

逐项验证进度见 Windows 移植 PR。遇到问题欢迎反馈。

常见问题

为什么要「屏幕录制」权限？

macOS 不允许一个 App 直接修改另一个 App 的窗口。Ghost 的做法是实时截取「窗口背后的画面」，铺在窗口上面，看起来就像窗口变透明了。截取画面需要这个权限。画面只在本机处理，不会保存或上传。

透明的窗口还能点吗？

能。Ghost 铺上去的那一层会让鼠标点击直接穿透到下面的真实窗口。

会不会很耗电？

普通透明模式开销很小。开启「共享时隐藏」并且有窗口被隐藏时，系统图形进程大约多用半个 CPU 核心；没有窗口被隐藏时没有额外开销。

Ghost 意外退出了，被隐藏的窗口会不会露出来？

有一个守护进程（活动监视器里叫 Ghost Watchdog）一直在窗口下面垫着色块。Ghost 崩溃或被强制退出时，色块会立刻顶上，然后 Ghost 自动重启、重新隐藏。如果在活动监视器里同时结束这两个进程，就没有保护了。

有 Windows 版吗？

有一个实验版（Beta）。交互和 macOS 版一致，但还没在真机上逐项验证，见上面的 Windows 版 区块。
